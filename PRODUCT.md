# Product

## Register

product

## Users

Technical evaluators, architects, and developers exploring a live Microsoft
Agent Framework and MCP on-behalf-of pattern. They use the interface to inspect
and change their own sample orders while validating that identity follows the
user through the full stack.

## Product Purpose

Show the delegated OBO architecture through a working order assistant rather
than a diagram or test script. Success means a user can sign in, ask natural
language questions, see the agent use MCP tools, and understand that the result
is scoped to their identity.

## Brand Personality

Polished, technical, trustworthy. The product should feel deliberate and
credible enough for an architecture demonstration without pretending to be a
production commerce system.

## Anti-references

- Generic ChatGPT clones with a centered logo, empty whitespace, and one floating
  prompt box.
- Decorative AI effects, neon gradients, glass panels, glowing orbs, and animated
  sparkles.
- Dense enterprise dashboards that obscure the simple conversation workflow.
- Interfaces that hide tool use or identity context behind vague "thinking"
  states.

## Design Principles

1. Make the identity boundary visible without turning the page into a security
   diagram.
2. Show useful system state, such as model, MCP connection, and signed-in user,
   only where it helps explain the demonstration.
3. Keep the conversation primary and order actions easy to scan.
4. Expose progress and errors plainly. Never make a failed tool call look like a
   successful answer.
5. Prefer familiar, restrained controls over novelty.

## Accessibility & Inclusion

Meet WCAG 2.2 AA. Support complete keyboard operation, visible focus, semantic
landmarks, assistive-technology announcements for new messages and errors, high
contrast in both themes, and reduced-motion preferences.
